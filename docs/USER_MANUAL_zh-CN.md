# ExplorerSider 使用手册（v1.0.0）

分层文件夹书签小工具——Clover 书签功能的独立替代品。

Windows 11 的"快速访问"不支持文件夹层级，Clover 已停止维护且在 Win11 上不稳定。ExplorerSider 以**悬浮书签栏 + 系统托盘**的形态提供完整的分层书签体验，不注入资源管理器、不修改系统，绿色免安装。

---

## 1. 系统要求与安装

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11（x64），支持多显示器 |
| 运行时 | **无需安装**（.NET 8 运行时已内嵌，单文件自包含） |
| 安装 | 无需安装：下载 `ExplorerSider.exe` 放到任意目录双击运行 |
| 磁盘 | 约 140 MB（exe 本体）+ 极少量配置 |
| 权限 | 普通用户权限即可；打开受保护目录时按需弹 UAC |

建议放入固定目录（如 `D:\Tools\ExplorerSider\`）再运行——开机自启会记住 exe 的当前路径。

## 2. 快速上手（5 步）

1. 双击 `ExplorerSider.exe`，屏幕顶部中央出现悬浮书签栏，托盘出现四叶草图标
2. 托盘右键 → **书签管理**（或直接把 Clover 备份 HTML 拖进管理窗口）
3. 菜单 `文件 → 导入书签`，选择 Clover 导出的 HTML 备份，选择**替换全部**或**合并**——书签、文件夹、图标、时间戳全部保留
4. 悬浮栏上**单击书签**即可直达对应文件夹；文件夹按钮**悬停**展开子列表
5. 托盘菜单开启**开机自启**

## 3. 悬浮书签栏

### 呼出与隐藏
- 默认停靠**屏幕顶部居中**，鼠标离开后自动收到边缘，仅露出 **2px** 细线（几乎不可见）
- 鼠标移到露出的边缘附近即自动滑出
- 全局热键 **`Ctrl+Alt+B`**：呼出/收起，作用于**鼠标当前所在的显示器**（多屏各自独立停靠）

### 停靠位置
右键悬浮栏左侧的**四叶草把手**，可选：顶部居中（默认）、左上角、右上角、左下角、右下角。四角模式是鼠标"天然陷阱"，指向角落即可唤出，命中率最高。

### 拖动
按住四叶草把手可临时拖动悬浮栏位置（切换停靠模式后以停靠位置为准）。

## 4. 书签与文件夹

### 基本操作
| 操作 | 方式 |
|---|---|
| 打开 | 单击书签 |
| 展开文件夹 | 悬停文件夹按钮，自动弹子列表；鼠标离开父按钮、子列表和右键菜单后自动收起 |
| 右键任意项 | 打开 / **以管理员身份打开**（UAC 提权）/ 编辑 / 删除 / 刷新图标 |
| 新建 | 点击悬浮栏右侧 **＋**：新建书签… / 新建文件夹… |
| 文件夹右键 | 额外提供"新建子书签" |

### 层级规则（v1.0.0 设计约束）
- 结构为 **根 → 文件夹 → 书签**，**仅支持一层文件夹**
- 文件夹不可拖入其他文件夹；右键不提供"新建子文件夹"

### 支持的路径类型
| 类型 | 示例 | 行为 |
|---|---|---|
| 本地目录 | `E:\Projects\Demo` | 资源管理器打开 |
| 局域网共享 / NAS | `\\192.168.1.10\share`、`\\NAS\media` | 资源管理器打开（离线时会提示不存在） |
| 虚拟位置 | `::{CLSID}`（控制面板、此电脑等） | 资源管理器打开 |
| 注册表 | `计算机\HKEY_LOCAL_MACHINE\...` | 自动用 regedit 定位到对应键 |
| 无权限目录 | 如 `systemprofile` | 自动检测并弹 UAC 提权打开 |

### 打开方式（`settings.json` 的 `FolderOpenMode`）
| 值 | 行为 |
|---|---|
| `SameWindow`（默认） | 在**当前已激活**的资源管理器窗口中跳转；若该路径已打开则直接置前已有窗口 |
| `NewWindow` | 每次开新窗口 |
| `NewTab` | 尝试在当前窗口新建标签页（Win11 24H2 对第三方限制较多，失败时自动回退为 SameWindow 行为） |

## 5. 拖拽

### 从资源管理器拖入（创建书签）
把文件/文件夹拖到：
- **悬浮栏空白/书签之间** → 在根级创建书签
- **文件夹按钮上** → 放入该文件夹（高亮提示）
- **管理窗口树/文件夹** → 同上

### 悬浮栏内部拖动（排序与移动）
- 拖动书签/文件夹左右移动 = **排序**（出现竖线指示）
- 书签拖到**文件夹按钮中部** = **移入文件夹**；拖到文件夹按钮**左右边缘（约 14px）** = 与文件夹排序
- 拖动时悬停文件夹按钮约 0.4 秒自动展开其子列表，可继续放入内部位置
- 文件夹本身只能在根级排序（不可移入其他文件夹）

### 管理窗口内部拖动
与悬浮栏同等能力：目标项上/下方出现**蓝色指示线**决定落点；拖到文件夹项中部 = 移入。

## 6. 管理窗口（托盘 → 书签管理）

- 树形视图总览全部书签/文件夹，双击编辑，右键快捷菜单
- 工具栏：新建书签 / 新建文件夹 / 编辑 / 删除 / 上移 / 下移 / 检查失效路径 / 刷新全部图标
- **多选批量操作**：`Ctrl+单击` 加选、`Ctrl+A` 全选、`Esc` 取消；删除时单击选中的项一并删除
- **检查失效路径**：后台扫描，失效书签以红色显示（对不可达的局域网路径已做后台化处理，不卡界面）
- **刷新全部图标**：重新抓取系统图标（同样后台执行）
- `文件` 菜单：导入/导出 HTML、打开数据目录、开机自启开关、退出

## 7. 系统托盘

四叶草图标（纯代码绘制，非素材）：
- 左键单击 / 双击：显示/隐藏悬浮书签栏
- 右键菜单：显示悬浮条、书签管理、导入书签、导出书签、开机自启（勾选）、退出

## 8. Clover 互导

- **导入**：Netscape Bookmark HTML（Clover / Chrome / Edge 通用格式），支持文件夹层级、`ICON`（base64 图标原样保留、与 Clover 像素级一致）、`ADD_DATE` 时间戳；导入时可选**替换全部**或**合并**为根下一个新文件夹
- **导出**：生成 UTF-8 BOM + CRLF 的同格式 HTML，可直接再导入 Clover/Chrome/Edge
- 可用命令行自检验验往返一致性（见第 10 节）

## 9. 数据与备份

| 内容 | 位置 |
|---|---|
| 书签数据 | `%APPDATA%\ExplorerSider\bookmarks.json`（人可读 JSON） |
| 设置 | `%APPDATA%\ExplorerSider\settings.json` |
| 自动备份 | 同目录 `bookmarks.json.bak.1 / .bak.2 / .bak.3`（每次保存滚动覆盖） |
| 开机自启 | 注册表 `HKCU\...\Run`（exe 移动位置后启动时自动刷新） |

**迁移到新电脑**：复制 `bookmarks.json` 即可；或导出 HTML 带走。

## 10. 命令行

```
ExplorerSider.exe --selftest <bookmarks.html>   # 自检：导入→导出→再导入，校验树完全等价
ExplorerSider.exe --genicon [输出.ico]          # 导出代码绘制的四叶草 .ico 文件
```

## 11. 设置项参考（settings.json）

| 键 | 默认 | 说明 |
|---|---|---|
| `HotkeyShowBar` | `Ctrl+Alt+B` | 呼出/收起热键（修改后重启程序生效） |
| `DockMode` | `1` | 1=顶部居中，2~5=四角（0=自由悬浮已废弃，加载时自动归一化为 1） |
| `ShowBar` | `true` | 悬浮条是否显示 |
| `FolderOpenMode` | `SameWindow` | 见第 4 节 |

## 12. 故障排除

| 现象 | 处理 |
|---|---|
| 热键无效且弹提示 | `Ctrl+Alt+B` 被其他程序占用；改 `settings.json` 的 `HotkeyShowBar` 后重启 |
| 悬浮栏找不到 | 按 `Ctrl+Alt+B`（鼠标放目标屏上）；或托盘左键；检查屏幕边缘 2px 细线 |
| 点书签没反应 | 若是局域网路径，确认对方开机在线；离线时会提示"不存在" |
| `NewTab` 模式仍开新窗口/原窗口 | Win11 24H2 限制，键盘模拟不可靠时自动回退——属预期保护行为 |
| 打开受保护目录无反应 | 稍候会弹 UAC；或右键"以管理员身份打开" |
| 图标不显示 | 右键 → 刷新图标；或管理窗口"刷新全部图标" |

## 13. 已知限制

- 悬浮书签栏为独立窗口，不内嵌在资源管理器内（Win11 无公开标签页 API，内嵌需注入 explorer，风险高、不做）
- 仅支持一层文件夹（有意设计，保持简单）
- 同名书签不做去重；拖动指示线在悬浮栏上有轻微视觉抖动（不影响落点准确性）
